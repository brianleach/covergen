# Corpus manifest

Generated by `scripts/corpus/build.ts`. One row is one Vitest test file plus
the one source file it imports most symbols from. Rows live in the gitignored
output directory as `corpus.jsonl`; this file and `stats.json` are the tracked record.

- Rows: 1476 (from 1491 candidate pairs)
- Duplicates dropped (whitespace-normalized test hash, across repos): 1
- Size ceiling: 23808 tokens of source plus test (p99 of source_plus_test tokens after dedupe, rounded up to a multiple of 256); 14 pairs over it dropped
- Tokenizer: cl100k_base (js-tiktoken). It is a proxy: the fine-tune model's own tokenizer will count differently.
- Seeds run: 23 of 23

## Provenance

Public tests may themselves have been written with an AI assistant; the builder
cannot know. The seed list leans to projects started before 2023 (valibot is the
exception), but a shallow clone carries no per-file history, so test files are not
dated, and many were rewritten after 2022. The corpus is not claimed to be free of
model text. It contains no covergen or Claude output: every row is a file read
verbatim from a public repository at the pinned commit.
